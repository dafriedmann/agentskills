# agentskills

Skills für Coding-Agents im [`SKILL.md`-Format](https://agentskills.io).

## Skills

| Skill | Beschreibung |
|---|---|
| [`intellij-run-changed-tests`](intellij-run-changed-tests/SKILL.md) | Führt die seit dem letzten Commit neuen oder geänderten Java/Kotlin-Tests im laufenden IntelliJ IDEA aus und fasst die Ergebnisse zusammen. |

## Installation

Den Skill-Ordner in das Skill-Verzeichnis des Agents kopieren oder verlinken, z. B. für Claude Code
nach `~/.claude/skills/`.

## Requirements
`>= Python 3.7` available in system path
